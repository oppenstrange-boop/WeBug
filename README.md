# WeBug

WeBug is a debugger.

This repository contains a lightweight debugging tool and a simple portfolio page.

## Files added

- `README.md` — this file with project overview and instructions.
- `portfolio.html` — a simple portfolio page you can customize and publish.

## Quick start

1. Open `portfolio.html` in a browser to view the portfolio page.
2. Customize the HTML with your name, projects, and contact info.

## How to contribute

1. Fork the repository.
2. Make your changes on a branch.
3. Send a pull request describing your changes.
